Maze tiles and icons

Style guide v1, 2026-11-14. Every tile and icon the maze draws, at game size, from the same code the maze walk uses (maze-art.js). Tune them here, then copy the values into maze-art.js › S, and the maze walk follows.

Visual goals

  • Every cell reads as part of a grid, at least subtly.
  • Start and goal are clear at a glance. Doors are clearly doors. Walls are clear.
  • The art style stays simple, but it must be clear.

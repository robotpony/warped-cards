# Saira Semi Condensed

The UI typeface for every build (decided 2026-11-16; `palette.json` › `fonts.ui`). Builds bundle these files from here; they MUST NOT keep their own copies in the repo.

- Weights: Regular (400), Medium (500), SemiBold (600), Bold (700). Add others from the same source only when a spec needs them.
- Source: Google Fonts, `ofl/sairasemicondensed` in github.com/google/fonts, fetched 2026-11-16.
- Licence: SIL Open Font License 1.1 (`OFL.txt`). "Saira" is a reserved font name: a changed version MUST be renamed.
- The font has no suit glyphs (♠ ♥ ♦ ♣) and no ★. Draw those from `design/neon/shapes.json` (ui.md › Type).
